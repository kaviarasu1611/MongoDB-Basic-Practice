MongoDB Basic Practice

Aim

To understand the basic concepts of MongoDB and perform database,
collection, CRUD, and query operations.

Objectives

Create a MongoDB database and collection.

Insert and retrieve documents.

Update and delete documents.

Understand MongoDB query operators.

Study a real-world Library System use case.

Technologies Used

MongoDB

MongoDB Shell

GitHub

Procedure

Created a database named studentDB.

Created a collection named students.

Inserted student documents containing name, age, course, and status.

Retrieved all student records.

Filtered students enrolled in the MERN Stack course.

Updated the status of selected students.

Deleted individual and multiple documents.

Practiced query operators such as greater than, less than, in, and,
or, and exists.

Created a Library System example using a books collection.

Operations Performed

Database and Collection Setup

A database named studentDB and a collection named students were
created successfully.

Insert Operation

Student records were added to the collection using single-document and
multiple-document insertion.

Read Operation

All student records were displayed, and students belonging to the MERN
Stack course were filtered.

Update Operation

The status of one student and multiple students was updated
successfully.

Delete Operation

One student record and all student records were deleted successfully.

Query Operators

The following MongoDB query operators were practiced:

$gt -- Greater than

$lt -- Less than

$in -- Matches any value from a list

$and -- Matches multiple conditions

$or -- Matches either condition

$exists -- Checks whether a field exists

Real-World Use Case: Library System

MongoDB can be used in a Library System to store and manage book details
such as:

Book title

Author

Category

Availability

The system can help librarians add books, search for books, update
availability, and remove old records.
